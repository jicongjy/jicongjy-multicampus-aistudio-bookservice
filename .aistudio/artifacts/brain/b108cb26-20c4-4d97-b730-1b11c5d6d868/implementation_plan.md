# AI 모델·API 키 설정 메뉴 및 도서 큐레이션·모니터링 콘솔 구축 계획

일반 손님 화면에서 개발자성 설정 UI를 분리하고, 관리자 콘솔 내에 전용 **[AI 모델 및 API 키 설정]** 탭을 신설하여 모델 프리셋 선택과 키 관리를 일원화합니다. 또한 운영 효율성을 극대화하기 위해 **[AI 호출 로그 모니터링]**과 **[도서 큐레이션 관리]** 기능을 통합 구축합니다.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> **확정된 요구사항 및 신규 기능 범위:**
> 1. **손님 화면 정돈 & 전용 설정 탭 통합**: 손님 독서 메뉴 화면에 있던 `AI 연결 설정` 아코디언을 관리자 콘솔 내부의 전용 **[AI 모델 & API 키 설정]** 탭으로 이전하여, 손님 화면은 군더더기 없는 감성적인 독서 메뉴판으로 복원합니다.
> 2. **AI 모델 프리셋 & 커스텀 입력 지원**:
>    - Claude 프리셋: `claude-3-5-haiku-20241022`, `claude-3-7-sonnet-20250219`, `claude-3-haiku-20240307`
>    - Gemini 프리셋: `gemini-3.8-flash`, `gemini-3.1-flash-lite`
>    - 기타 신규 모델을 위한 사용자 수동 모델명 입력창 병행 제공
> 3. **실시간 AI 호출 로그 모니터링**:
>    - 손님 메모 분석 및 이유 생성 시 발생한 최근 호출 기록(요청 시각, 요청 유형, 사용 엔진/모델, 소요 시간 ms, 성공/실패 여부)을 테이블로 시각화
> 4. **감정별 추천 도서 큐레이션 관리 (CRUD)**:
>    - 8가지 감정(설렘, 지침, 외로움 등)에 매핑된 책(제목, 저자, 기본 소개문)을 관리자가 직접 추가, 수정, 삭제할 수 있도록 지원하며, 수정된 도서 목록이 손님의 영수증 추천 알고리즘 및 YES24 링크에 실시간 반영됩니다.

---

### 1. Overview & Core Concept

- **목적**: AI 엔진 설정, 프롬프트 튜닝, 추천 도서 데이터, 시스템 모니터링을 단일 관리자 화면에서 모두 통제할 수 있는 통합 SaaS형 백오피스 환경 구축
- **핵심 가치**:
  1. **손님 UX 순수성 복원**: 일반 이용자에게 API 키나 모델 이름 등 불필요한 기술적 정보가 노출되지 않고 몰입감 유지
  2. **운영 자율성**: 소스 코드 수정 없이 관리자가 도서를 추가/수정하거나 최신 AI 모델로 즉시 전환
  3. **신뢰성 & 관측성(Observability)**: 호출 성공/실패 및 지연 시간(`latencyMs`)을 로그로 실시간 확인하여 API 장애 즉각 인지

---

### 2. User Experience & Visual Design

#### A. 손님 독서 메뉴 화면 변경사항
- 기존 3단계 메모 영역 하단의 복잡한 `AI 연결 설정` 아코디언 박스를 제거합니다.
- 대신 상단 모드 바에서 현재 시스템이 정상 작동 중임을 알리는 미니멀한 텍스트 상태만 유지하여, 손님은 책과 감정에만 온전히 집중할 수 있습니다.

#### B. 관리자 콘솔 전용 탭 구조
관리자 콘솔을 4개의 고밀도 유틸리티 탭으로 체계화합니다:

1. **탭 1: AI 모델 & API 키 설정 (신설)**
   - AI 공급자 토글: `Claude (Anthropic)` vs `Gemini (Google AI Studio)`
   - 모델 선택: 최신 추천 모델 원클릭 프리셋 버튼 + 수동 모델명 입력
   - API 키 및 워크스페이스 ID 마스킹 입력 필드
   - `[연결 테스트 및 저장]` 버튼으로 즉시 유효성 검증

2. **탭 2: 프롬프트 제어 & 튜닝 (기존 고도화)**
   - 감정 분석 프롬프트(`{text}`, `{emotionList}`)
   - 맞춤 이유 작성 프롬프트(`{memo}`, `{emotion}`, `{mainTitle}`, `{sideTitle}` 등)
   - 시스템 지시문 및 하이퍼파라미터(Temperature, Max Tokens) 슬라이더

3. **탭 3: 감정별 추천 도서 큐레이션 관리 (신설)**
   - 좌측: 8대 감정 선택 리스트
   - 우측: 선택된 감정의 추천 도서 목록 테이블 (제목, 저자, 기본 소개문)
   - `[새 도서 추가]`, `[도서 정보 편집]`, `[삭제]` 기능 제공
   - YES24 검색 바로가기 미리보기 링크 제공

4. **탭 4: AI 호출 모니터링 로그 (신설)**
   - 최근 AI 요청 내역을 시간 역순으로 표시하는 컴팩트 데이터 테이블
   - 컬럼: 요청 일시 (`tabular-nums`), 작업(감정분석/이유생성/테스트), 공급자/모델, 응답시간(`ms`), 결과 상태(성공 200 / 에러 코드)
   - `[로그 비우기]` 및 실패 건 상세 에러 메시지 팝오버 확인

5. **우측 고정: 실시간 검증 플레이그라운드**
   - 변경한 모델, 키, 프롬프트, 도서 데이터를 실제 호출하여 즉시 검증하는 샌드박스 유지

---

### 3. Key Product Decisions & Trade-Offs

- **도서 데이터의 클라이언트 & 로컬스토리지 영속화**:
  - *결정*: 기본 32권의 정적 도서 데이터를 기반으로 하되, 관리자가 추가/수정한 내용을 `localStorage`(`cfg_books_data`)에 보존하여 앱 전체와 실시간 동기화
  - *이유*: 별도의 복잡한 외부 DB 구축 없이도 브라우저 상에서 즉시 안전하게 작동하며, 언제든 기본 도서 데이터로 원클릭 롤백 가능
- **호출 로그 인메모리 & 로컬 저장 (최근 50건)**:
  - *결정*: 과도한 메모리 누수를 방지하기 위해 최근 50개의 AI 요청 기록을 순환 큐(Circular Queue) 형태로 보존
  - *이유*: 실시간 지연시간 비교 및 오류 파악에 충분한 데이터를 가볍고 빠르게 제공

  id: string;
  title: string;

  id: string;
  timestamp: string;

  status: 'success' | 'error';
